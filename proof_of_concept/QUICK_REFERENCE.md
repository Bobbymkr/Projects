### Windows
```batch

```


## 🔧 Troubleshooting

**Issue**: Python not found  
**Fix**: Install Python 3.8+ from python.org

**Issue**: NumPy error  
**Fix**: `pip install numpy` (or let launcher auto-install)

**Issue**: POC takes too long  
**Fix**: Edit `POC_CONFIG["traffic_episodes"]` to 10 for faster demo

**Issue**: Can't open HTML dashboard  
**Fix**: Manually open `poc_results/poc_dashboard.html` in browser

## 📞 Quick Questions

**Q**: Can I skip phases?  
**A**: Yes, comment out phases in `main()` function

**Q**: Can I run multiple times?  
**A**: Yes, results are timestamped and saved

**Q**: Can I customize scenarios?  
**A**: Yes, edit `poc_config.json`

**Q**: Is internet required?  
**A**: No, runs completely offline (after dependencies installed)

**Q**: Can I share the dashboard?  
**A**: Yes, `poc_dashboard.html` is standalone
