## 📞 Support & Questions

### **Common Questions**

**Q: How long does the POC take to run?**  
A: Approximately 10 minutes for the full demonstration.

**Q: What if I don't have NumPy installed?**  
A: The launcher script will automatically install it for you.

**Q: Can I run a shorter demo?**  
A: Yes, modify `POC_CONFIG["traffic_episodes"]` to 10 for a 5-minute version.

**Q: Where are the results saved?**  
A: In the `poc_results/` directory - JSON, HTML, and regional configs.

**Q: Can I customize the scenarios?**
